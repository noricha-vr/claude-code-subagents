# 日本株価レポートシステム実装計画

## 全体目標
日本の主要株価指数と銘柄を自動収集し、本日の市場サマリーをHTML形式で出力する株価レポートシステムを構築する。

## アーキテクチャ概要
- **Collector**: yfinanceによる株価データ収集
- **Processor**: 市場動向分析と銘柄パフォーマンス評価
- **Generator**: HTMLレポート生成（Jinja2テンプレート）
- **Scheduler**: 平日自動実行機能
