# 🚀 シンプル化されたワークフローシステム

## 📋 設計原則

### 1. **メインエージェントがオーケストレーション**
- サブエージェントではなく、メインエージェント（Claude自身）が直接管理
- 各サブエージェントを明示的に順番に呼び出し
- ターミナルで進捗が見える

### 2. **最小限のファイル管理**
- 複雑な状態ファイルを廃止
- 1つのコンテキストファイルのみ使用: `docs/context.md`
- エージェント間の受け渡しはコンテキスト内に記述

### 3. **シンプルなフロー**
```
メインエージェント
    ↓ 計画が必要
    @planner → docs/context.md更新
    ↓ 実装が必要
    @executor → docs/context.md参照して実装
    ↓ レビューが必要
    @reviewer → 実装をレビュー
    ↓ 
    ループ
```

## 🎯 実装方法

### ステップ1: 計画フェーズ
```bash
# メインエージェントから直接呼び出し
@planner "タスク: ユーザー認証機能を実装"
# → docs/context.mdに計画を記録
```

### ステップ2: 実装フェーズ
```bash
# メインエージェントが判断して呼び出し
@executor "docs/context.mdの現在のステップを実装"
# → 実装結果をdocs/context.mdに追記
```

### ステップ3: レビューフェーズ
```bash
# メインエージェントが判断して呼び出し
@reviewer "直前の実装をレビュー"
# → レビュー結果をdocs/context.mdに追記
```

## 📝 コンテキストファイル構造

`docs/context.md`:
```markdown
# ワークフローコンテキスト

## 現在の状態
- フェーズ: planning | executing | reviewing
- ステップ: 1/10
- 最終更新: 2025-08-07 12:00

## 計画
[plannerの出力]

## 実装結果
[executorの出力]

## レビュー結果
[reviewerの出力]

## 次のアクション
[メインエージェントが判断]
```

## 🔄 メインエージェントのロジック

```python
# 擬似コード
def manage_workflow(task):
    # 1. 計画作成
    print("📋 計画フェーズ開始")
    call_agent("@planner", task)
    
    # 2. context.mdを読んで計画を確認
    context = read("docs/context.md")
    steps = extract_steps(context)
    
    # 3. 各ステップを実行
    for step in steps:
        print(f"🔨 実装: {step}")
        call_agent("@executor", f"実装: {step}")
        
        print("👁️ レビュー実施")
        call_agent("@reviewer", "直前の実装をレビュー")
        
        # レビュー結果を確認
        if has_critical_issues():
            print("🔧 修正が必要")
            call_agent("@executor", "レビュー指摘を修正")
        
    print("✅ 完了")
```

## 🎯 利点

1. **可視性の向上**
   - メインエージェントが各ステップを明示的に実行
   - ターミナルで進捗が見える

2. **シンプルな管理**
   - 1つのコンテキストファイルのみ
   - 複雑な状態管理不要

3. **柔軟性**
   - メインエージェントが状況に応じて判断
   - 必要に応じてステップをスキップ可能

## ⚡ クイックスタート

### 方法1: 手動オーケストレーション
```bash
# タスク開始
"動画→MP3変換アプリを作成します。まず計画を立てます。"

# plannerを呼び出し
@planner "動画→MP3変換ウェブアプリケーションの実装計画"

# 計画確認後、実装
@executor "計画のStep 1を実装"

# レビュー
@reviewer "実装内容をレビュー"
```

### 方法2: 半自動オーケストレーション
メインエージェントに以下を依頼：
```
「動画→MP3変換アプリを作成してください。
計画→実装→レビューのフローで進めてください。
各ステップでサブエージェントを適切に呼び出してください。」
```
