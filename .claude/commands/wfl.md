# /wfl - ワークフローループ（詳細版）

## 使い方
```bash
/wfl タスクの説明
```

## このコマンドの意味

以下の指示と同等です：
```
「[タスク]を実装してください。

重要：以下のループを全ステップ完了まで繰り返してください：
1. @agent-plannerで次のステップを計画
2. @agent-executorで1ステップだけ実装
3. @agent-reviewerでレビュー
4. レビュー結果に基づいて1に戻る

各ステップ完了後、必ず次のステップに進んでください。
全体の進捗はdocs/context.mdで管理してください。
私から停止指示があるまで自動的に継続してください。」
```

## 短縮版との違い
- `/wf` - シンプルにループ実行
- `/wfl` - 明示的にループ動作を私に認識させる
