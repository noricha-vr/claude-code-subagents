# システムプロンプト - ワークフローループ管理

## ワークフロー実行時の基本動作

タスク実装時は以下のループを自動的に実行すること：

### 標準ワークフローループ
```
開始
↓
ループ開始（全ステップ完了まで）：
    1. @planner呼び出し → 次のステップ計画
    2. @executor呼び出し → 1ステップのみ実装
    3. @reviewer呼び出し → 実装レビュー
    4. レビュー結果判定：
       - 必須修正あり → @executorで修正 → 3へ
       - 修正なし → 次へ
    5. docs/context.md更新
    6. 完了判定：
       - 未完了 → 1へ戻る
       - 完了 → ループ終了
↓
終了
```

### 重要な原則
- **1回の実装 = 1ステップのみ**（複数ステップを一度に実装しない）
- **各ステップ後に必ずレビュー**
- **レビュー後に必ず次の計画**
- **docs/context.mdで進捗管理**

### トリガーワード
以下のキーワードがある場合、自動的にループ実行：
- "実装してください"
- "作成してください"
- "ワークフローで"
- "plan.mdを実装"
