# Claude Code エージェント設定テンプレート

Claude Codeのサブエージェント機能を活用した開発ワークフローの設定テンプレートです。

## 概要

このプロジェクトは、Claude Codeの`.claude/`ディレクトリを使用して、カスタムエージェントとコマンドを定義し、効率的な開発ワークフローを構築するためのテンプレートです。

## 主な機能

### 🚀 ワークフローコマンド (`/wf`)
タスクを自動的に計画・実装・レビューのサイクルで完了まで実行します。

```bash
/wf タスクの説明
```

例：
```bash
/wf ユーザー認証機能を追加
/wf READMEファイルを作成
/wf バグ修正とテスト追加
```

### 📦 サブエージェント

#### @agent-planner (計画エージェント)
- タスクを実装可能な小さなステップに分解
- 1ステップ = 5分以内の作業
- `docs/context.md`に計画を記録

#### @agent-executor (実装エージェント)
- 計画に基づいて実際にコードを実装
- 1ステップごとに実行
- 実装結果を`docs/context.md`に記録

#### @agent-reviewer (レビューエージェント)
- 実装内容をレビュー
- 品質・セキュリティ・パフォーマンスを確認
- 合格時は自動的にgit commit

## ディレクトリ構造

```
.claude/
├── agents/           # サブエージェント定義
│   ├── planner.md   # 計画エージェント
│   ├── executor.md  # 実装エージェント
│   └── reviewer.md  # レビューエージェント
└── commands/        # カスタムコマンド定義
    └── wf.md        # ワークフローループコマンド

docs/
└── context.md       # ワークフロー進捗管理ファイル
```

## 使い方

### 1. 初期設定

プロジェクトルートに`.claude/`ディレクトリをコピーします：

```bash
cp -r .claude/ /path/to/your/project/
```

### 2. ワークフロー実行

タスクを指定してワークフローを開始：

```bash
/wf 実装したいタスクの説明
```

### 3. 進捗確認

実行中の進捗は`docs/context.md`で確認できます。

### 4. 停止方法

- Ctrl+C または「停止」と入力
- 特定のステップで停止：「Step Xで停止」

## ワークフローの流れ

```mermaid
graph TD
    A[タスク開始] --> B[@agent-planner<br/>計画作成]
    B --> C[@agent-executor<br/>1ステップ実装]
    C --> D[@agent-reviewer<br/>レビュー]
    D --> E{レビュー結果}
    E -->|要修正| F[@agent-executor<br/>修正実装]
    F --> D
    E -->|合格| G[git commit]
    G --> H{全ステップ完了?}
    H -->|No| B
    H -->|Yes| I[完了]
```

## カスタマイズ

### エージェントのカスタマイズ

各エージェントの動作は`.claude/agents/`内のMarkdownファイルで定義されています：

- `planner.md`: 計画の粒度や形式を調整
- `executor.md`: 実装ルールや制約を設定
- `reviewer.md`: レビュー観点や判定基準を変更

### コマンドの追加

新しいコマンドを追加するには、`.claude/commands/`に新しいMarkdownファイルを作成：

```markdown
---
name: mycommand
description: カスタムコマンドの説明
---

# コマンドの詳細な説明と実装内容
```

## 特徴

- **自動化**: 計画から実装、レビューまで自動実行
- **品質保証**: 各ステップでレビューを実施
- **進捗管理**: `docs/context.md`で常に進捗を確認可能
- **Git連携**: レビュー合格時に自動コミット
- **柔軟性**: エージェントやコマンドをカスタマイズ可能

## 必要要件

- Claude Code (最新版)
- Git
- プロジェクトルートに`.claude/`ディレクトリの配置権限
